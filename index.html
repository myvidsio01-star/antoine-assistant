Tutoriels

Configurer vos clés API

Guides pas-à-pas pour générer vos clés sur chaque plateforme. Tout est gratuit sauf mention contraire.

⚡ Groq Cloud — Génération de clé API RECOMMANDÉ — MOTEUR PRINCIPAL ▼

✅ 100% gratuit, aucune carte bancaire requise. C'est le moteur principal d'A.N.T.O.I.N.E — commencez impérativement par celui-ci.

  1. Allez sur console.groq.com et cliquez sur "Sign Up" pour créer un compte gratuit (vous pouvez aussi vous connecter directement avec Google).
  2. Une fois sur le tableau de bord, dans le menu de navigation à gauche, cliquez sur "API Keys".
  3. Cliquez sur le bouton "Create API Key", donnez-lui un nom reconnaissable (par exemple : antoine), puis confirmez.
  4. Copiez la clé affichée — elle commence par gsk_. Attention : elle n'est visible qu'une seule fois, notez-la immédiatement.
  5. Ouvrez votre fichier .env dans le dossier A.N.T.O.I.N.E et collez la clé après : GROQ_API_KEY=
  6. Sauvegardez le fichier et lancez A.N.T.O.I.N.E. Le moteur Groq est opérationnel, aucune autre action n'est requise.
🤖 Gemini AI — Créer une clé API ▼

Moteur de secours (fallback 1) — gratuit sur le tier standard. Utilisé automatiquement si Groq est indisponible.

  1. Rendez-vous sur aistudio.google.com et connectez-vous avec votre compte Google.
  2. Cliquez sur "Get API key" en haut à gauche de l'interface.
  3. Cliquez sur "Create API key" et sélectionnez un projet Google Cloud (ou créez-en un nouveau).
  4. Copiez la clé générée et collez-la dans votre .env sous GEMINI_API_KEY=
  5. Sauvegardez le fichier. A.N.T.O.I.N.E basculera automatiquement sur Gemini si Groq est indisponible.
🧠 Claude (Anthropic) — Clé API ▼

⚠️ Les nouveaux comptes sur console.anthropic.com reçoivent 5$ de crédits gratuits à l'inscription — profitez-en pour tester Claude sans payer.

  1. Allez sur console.anthropic.com et créez un compte. Les nouveaux utilisateurs reçoivent automatiquement 5$ de crédits offerts pour débuter.
  2. Une fois connecté, rendez-vous dans la section "API Keys" depuis le menu de navigation.
  3. Cliquez sur "Create Key", donnez-lui un nom (ex : antoine) et confirmez la création.
  4. Copiez la clé (commence par sk-ant-) et collez-la dans votre fichier .env sous ANTHROPIC_API_KEY=
  5. Sauvegardez. Claude sera utilisé en fallback secondaire si Groq et Gemini sont indisponibles.
📺 YouTube Data API — Accès vidéos ▼
  1. Allez sur console.cloud.google.com
  2. Créez un nouveau projet Google Cloud
  3. Activez l'API "YouTube Data API v3" depuis la bibliothèque
  4. Dans "Identifiants", créez une clé API
  5. Copiez-la dans YOUTUBE_API_KEY=
🤖 Grok (X.ai) — Clé API ▼
  1. Allez sur console.x.ai
  2. Connectez-vous avec votre compte X (Twitter)
  3. Dans le menu, cliquez sur "API Keys"
  4. Créez une nouvelle clé et copiez-la dans GROK_API_KEY=
🔍 SerpAPI — Résultats de recherche ▼
  1. Allez sur serpapi.com
  2. Créez un compte gratuit (100 requêtes/mois offertes)
  3. Dans votre dashboard, copiez votre API Key
  4. Ajoutez-la dans SERPAPI_KEY=
🏠 Home Assistant — Token longue durée ▼
  1. Connectez-vous à votre interface Home Assistant
  2. Cliquez sur votre profil (en bas à gauche)
  3. Faites défiler jusqu'à "Jetons d'accès longue durée"
  4. Cliquez sur "Créer un jeton", donnez-lui un nom
  5. Copiez-le dans HA_TOKEN= et renseignez HA_URL=
