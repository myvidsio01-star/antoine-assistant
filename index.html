1 Téléchargement

Installez A.N.T.O.I.N.E sur votre machine

Choisissez votre système d'exploitation et suivez les instructions. Python 3.10+ requis.

🪟

Windows

Installation recommandée pour la majorité des utilisateurs. Compatible Windows 10/11.

pip install -r requirements.txt
python antoine.py
⬇ Télécharger Python 3.12
🍎

macOS

Compatible Apple Silicon et Intel. Homebrew recommandé pour les dépendances audio.

pip3 install -r requirements.txt
python3 antoine.py
🐧

Linux

Testé sur Ubuntu 22.04+, Debian et dérivés. Portaudio requis pour le micro.

sudo apt install portaudio19-dev
pip install -r requirements.txt
💡 Première installation ? Téléchargez l'archive complète via le bouton ci-dessous, extrayez le dossier, installez Python 3.10+ si ce n'est pas déjà fait, puis suivez l'Étape 2 pour configurer votre fichier .env avec vos clés API.
2 Personnalisation

Configurez votre assistant

Ajoutez vos clés API, personnalisez les préférences et activez les modules dont vous avez besoin.

📁

Fichier .env

Dans le dossier A.N.T.O.I.N.E, renommez .env.example en .env, puis ouvrez-le avec un éditeur de texte et remplissez vos clés. Ne le partagez jamais — il contient vos secrets.

# Moteur principal (recommandé)
GROQ_API_KEY=gsk_xxxxxxxxxxxx
# Moteurs secondaires (optionnels)
GEMINI_API_KEY=AIzaxxxxxxxxx
ANTHROPIC_API_KEY=sk-ant-xxxxxx
# Intégrations
HA_TOKEN=votre_token_ha
HA_URL=http://homeassistant.local:8123
🔑

Clés API — lesquelles obtenir ?

Seule la clé Groq est indispensable — c'est le moteur principal, rapide et 100% gratuit. Les autres (Gemini, Claude) sont optionnelles et servent de fallback automatique si Groq est indisponible.

Voir les guides ci-dessous pour obtenir chaque clé en 2 minutes.

📱

Accès mobile

Une interface companion est disponible pour smartphone, synchronisée avec votre instance A.N.T.O.I.N.E locale via le réseau Wi-Fi. Contrôlez A.N.T.O.I.N.E depuis n'importe quelle pièce.

Lancer A.N.T.O.I.N.E

Une fois le .env configuré avec au moins votre clé Groq, lancez A.N.T.O.I.N.E et dites "Antoine" pour activer la reconnaissance vocale.

Tutoriels

Configurer vos clés API

Guides pas-à-pas pour générer vos clés sur chaque plateforme. Tout est gratuit sauf mention contraire.

🤖 Gemini AI — Créer une clé API ▼
  1. Rendez-vous sur aistudio.google.com
  2. Connectez-vous avec votre compte Google
  3. Cliquez sur "Get API key" en haut à gauche
  4. Cliquez sur "Create API key"
  5. Copiez la clé dans votre .env sous GEMINI_API_KEY=
⚡ Groq Cloud — Génération de clé API RECOMMANDÉ EN PREMIER ▼

✅ 100% gratuit, aucune carte bancaire requise. C'est le moteur principal d'A.N.T.O.I.N.E — commencez par celui-ci.

  1. Allez sur console.groq.com
  2. Cliquez sur "Sign Up" et créez un compte gratuit (ou connectez-vous avec Google)
  3. Une fois connecté, dans le menu de gauche, cliquez sur "API Keys"
  4. Cliquez sur "Create API Key", donnez-lui un nom (ex: "antoine")
  5. Copiez la clé affichée (commence par gsk_) — elle n'apparaît qu'une seule fois
  6. Dans votre fichier .env, collez-la après : GROQ_API_KEY=
🧠 Claude (Anthropic) — Clé API ▼

⚠️ Nécessite un crédit minimum de 5$ pour activer l'API.

  1. Allez sur console.anthropic.com
  2. Créez un compte et ajoutez 5$ de crédit (carte bancaire)
  3. Cliquez sur "API Keys" dans le menu
  4. Créez une nouvelle clé et copiez-la dans ANTHROPIC_API_KEY=
📺 YouTube Data API — Accès vidéos ▼
  1. Allez sur console.cloud.google.com
  2. Créez un nouveau projet Google Cloud
  3. Activez l'API "YouTube Data API v3" depuis la bibliothèque
  4. Dans "Identifiants", créez une clé API
  5. Copiez-la dans YOUTUBE_API_KEY=
🤖 Grok (X.ai) — Clé API ▼
  1. Allez sur console.x.ai
  2. Connectez-vous avec votre compte X (Twitter)
  3. Dans le menu, cliquez sur "API Keys"
  4. Créez une nouvelle clé et copiez-la dans GROK_API_KEY=
🔍 SerpAPI — Résultats de recherche ▼
  1. Allez sur serpapi.com
  2. Créez un compte gratuit (100 requêtes/mois offertes)
  3. Dans votre dashboard, copiez votre API Key
  4. Ajoutez-la dans SERPAPI_KEY=
🏠 Home Assistant — Token longue durée ▼
  1. Connectez-vous à votre interface Home Assistant
  2. Cliquez sur votre profil (en bas à gauche)
  3. Faites défiler jusqu'à "Jetons d'accès longue durée"
  4. Cliquez sur "Créer un jeton", donnez-lui un nom
  5. Copiez-le dans HA_TOKEN= et renseignez HA_URL=
