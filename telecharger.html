FAQ Téléchargement

Questions fréquentes

Les problèmes les plus courants lors de l'installation, et comment les résoudre.

Je n'ai pas reçu le mot de passe ▼
Le mot de passe est envoyé automatiquement après validation de votre donation. Si vous ne le recevez pas dans les 5 minutes, rendez-vous sur notre Discord et ouvrez un ticket dans le canal #aide-installation. Un membre de l'équipe vous répondra rapidement.
Erreur PyAudio lors de l'installation ▼
PyAudio est parfois difficile à installer directement sur Windows. Utilisez pipwin à la place — c'est un outil qui simplifie l'installation des paquets audio sur Windows :

pip install pipwin
puis
pipwin install pyaudio

Relancez ensuite pip install -r requirements.txt et tout devrait fonctionner.
A.N.T.O.I.N.E ne comprend pas ma voix ▼
Voici les choses à vérifier dans l'ordre :

1. Assurez-vous que votre microphone est bien sélectionné comme périphérique d'entrée par défaut dans les paramètres Windows (Paramètres → Son → Entrée).
2. Parlez clairement et en français — A.N.T.O.I.N.E est optimisé pour le français.
3. Évitez les environnements très bruyants. Un micro casque donne de meilleurs résultats qu'un micro intégré.
4. Si le problème persiste, ouvrez un ticket sur le Discord dans #aide-installation.
