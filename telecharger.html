Questions fréquentes

Les problèmes les plus courants lors de l'installation, et comment les résoudre.

⚠️ Erreur PyAudio lors de l'installation ▼
PyAudio est parfois difficile à installer sur Windows. La solution la plus simple est de le réinstaller directement avec pip :

pip install PyAudio

Si cette commande échoue aussi, utilisez pipwin (un outil spécialisé Windows) :

pip install pipwin
puis
pipwin install pyaudio

Relancez ensuite setup.bat ou pip install -r requirements.txt et tout devrait fonctionner.
🎤 Antoine ne comprend pas ma voix ▼
Le problème vient souvent du microphone. Voici comment le vérifier :

1. Allez dans Paramètres Windows → Son → Entrée
2. Vérifiez que votre microphone est sélectionné comme périphérique d'entrée par défaut
3. Parlez clairement et en français — A.N.T.O.I.N.E est optimisé pour le français
4. Évitez les environnements très bruyants. Un micro casque donne de meilleurs résultats qu'un micro intégré

Si le problème persiste, ouvrez un ticket sur notre Discord.
🤖 Aucune réponse de l'IA ▼
Ce problème vient presque toujours de la clé API. Voici quoi vérifier :

1. Ouvrez votre fichier .env (à la racine du dossier d'A.N.T.O.I.N.E)
2. Vérifiez que votre clé Groq est bien collée après GROQ_API_KEY= — sans espace, sans guillemets
3. Assurez-vous que la clé est bien active sur console.groq.com
4. Vérifiez que le fichier s'appelle bien .env et non .env.example ou .env.txt

Si tout semble correct mais que ça ne fonctionne toujours pas, rejoignez notre Discord pour obtenir de l'aide.
