Politique de Confidentialité

✅ Ce site ne vend aucune donnée personnelle

Données collectées

Ce site web ne collecte aucune donnée personnelle automatiquement. Aucun cookie de tracking, aucune analytics, aucun formulaire d'inscription n'est présent sur ce site.

Le logiciel A.N.T.O.I.N.E

Le logiciel A.N.T.O.I.N.E fonctionne localement sur votre machine. Il ne transmet aucune donnée à nos serveurs. Les données envoyées aux services IA tiers (Gemini, Groq, Claude, etc.) sont régies par leurs propres politiques de confidentialité :

  • Google / Gemini
  • Groq
  • Anthropic / Claude

Hébergement

Ce site est hébergé sur GitHub Pages. GitHub peut collecter certaines données techniques (adresse IP, navigateur) dans ses logs serveur. Consultez la politique de confidentialité de GitHub.

Vos droits

Conformément au RGPD, vous disposez d'un droit d'accès, de rectification et de suppression de vos données. Puisque nous ne collectons aucune donnée, aucune action n'est nécessaire de votre part.
